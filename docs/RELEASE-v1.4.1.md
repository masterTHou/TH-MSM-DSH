# TH-MSM v1.4.1 — 插件入口兼容性修复

## 修复

v1.4.0 的条件导出只声明 `types` 与 `import`。直接 ESM 导入可用，但先通过 `require.resolve` 查找入口的宿主会抛出 `ERR_PACKAGE_PATH_NOT_EXPORTED`。本次为插件及公共子模块增加 `default` 导出条件，保持编译后的 ESM 与类型声明。

## 验证

- 插件包名与四个公共子模块的解析、动态导入回归测试。
- 从真实 `.tgz` 解压到仓库外，只提供主机 peer dependencies；验证入口解析、完整导入、12 个工具注册与教学工具执行。
- 科学计算、对话流程与 TypeScript 检查继续执行。

本机 DSH 的实际配置解析器也可导入原 v1.4.0；因此不能仅凭汇总警告断定用户当时的原始异常。此补丁修复已复现的入口缺陷，并提供刷新安装与重启步骤。

## 更新

安装本 Release 的 `th-msm-dsh-plugin-1.4.1.tgz`。保存工作后完全退出并重新打开 DSH，清除之前加载的模块与失败缓存。若仍无法启用，请保留提示之前的原始异常与 DSH 版本，以定位具体依赖或加载问题。
