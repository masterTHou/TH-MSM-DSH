# Trajectory Hub for Markov State Modeling (TH-MSM) v1.5.1

**TH = Trajectory Hub；MSM = Markov State Modeling。**

中文名称：马尔可夫态建模轨迹工作台。

本次统一项目名称、GitHub 仓库与链接、主 README、横幅、Codex README、DSH/Codex 展示信息、marketplace 名称展示、MCP 服务标题与技能介绍。缩写保留 TH-MSM，已有 `th-msm` 插件 ID 与 `th_msm_*` 工具名保持兼容。

## Codex 安装

```sh
codex plugin marketplace add masterTHou/Trajectory-Hub-for-Markov-State-Modeling-TH-MSM --ref v1.5.1
codex plugin add th-msm@th-msm-plugins
```

需要 Node.js ≥22。安装后新开对话，选择 Trajectory Hub for Markov State Modeling (TH-MSM)。

## 安装包

- `th-msm-dsh-plugin-1.5.1.tgz`：DSH 插件。
- `th-msm-codex-plugin-1.5.1.tar.gz`：独立 Codex 插件本体。
- `PROVENANCE.json` 与 `SHA256SUMS.txt`：构建与校验记录。

本次为名称与展示信息更新，科学算法和验证边界沿用 v1.5.0。GitHub 分发不等于 OpenAI 公共插件目录上架。
