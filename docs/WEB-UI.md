# TH-MSM 交互网页使用手册

适用版本：v1.7.0。面向第一次接触 MSM 的本科生，也面向需要快速检查模型的研究者。

## 1. 不安装插件也能体验

1. 在 [GitHub Releases](https://github.com/masterTHou/Trajectory-Hub-for-Markov-State-Modeling-TH-MSM/releases/latest) 下载 **th-msm-web.html**。
2. 双击文件，用 Chrome、Edge 或 Firefox 打开。无需 Node.js、Python、账号或服务器。
3. 点击 **打开两状态教学示例**。这是合成马尔可夫链，不是实际分子模拟。
4. 页面包含所有脚本和样式，不使用 CDN，不上传数据；可断网使用。

如果浏览器拦截本地文件，请通过浏览器“打开文件”选择该 HTML；源码用户也可以使用下方的本地网页命令。

## 2. 在 Codex / DSH 插件里使用

安装或更新到 v1.7.0 后，在项目聊天中输入：

> 请用 TH-MSM 生成交互教学网页，保存到 output/msm-dashboard.html，并打开给我看。我是本科生，请从两状态示例开始解释。

已有模型：

> 把 output/msm/model.json 生成交互网页，保存到 output/my-msm.html。解释转移矩阵、布居、MFPT 和验证结论。

工具：`th_msm_view`，可选参数 `modelPath`、`outputPath`。Codex 需要额外传入用户选择的绝对 `workspaceRoot`；DSH 使用当前会话工作区。工具返回 `dashboardPath`；用浏览器打开此文件。输出路径必须位于工作区。

完整自动流程：

> 用 TH-MSM 运行两状态示例全流程，结果放在一个新的输出目录，生成模型、验证、报告和交互网页。

`th_msm_run` 完成后，结果目录新增 **dashboard.html**，`run-manifest.json` 的 `artifacts.dashboard` 记录实际路径。已有目录仍会拒绝覆盖；单独 `th_msm_view` 可更新指定 HTML。网页生成失败时，工作流会记录失败阶段。

## 3. 按什么顺序看页面？

### 第一站：状态网络与矩阵

点击圆点，或使用“起点”下拉框。箭头表示一个 lag 后的转移概率；自留概率请在表格中查看。圆点面积代表长期布居，网络布局不代表分子几何、能垒或反应坐标。

矩阵行是当前状态，列是未来状态。例如示例中的 P01 约 0.1：当前在状态 0，过一个 lag 后约有 10% 概率在状态 1。点击格子会自动翻译成一句话。**对角线高表示在这个 lag 后仍处于原状态，不意味着中间一定没离开过。**

示例真实转移矩阵为 `[[0.9,0.1],[0.2,0.8]]`，网页展示的是由有限轨迹估计得到的值，允许有采样误差。

### 第二站：布居与分布演化

长期布居回答“长时间观察在哪个状态待得多”。示例理论布居约为 2/3 与 1/3。

拖动“走几个 lag”的滑块，查看从当前起点出发的概率分布如何变化。网页计算 `p(n)=p(0)P^n`，没有重新模拟轨迹。比较第 0 步和第 20 步；为什么初始状态的影响逐渐减弱？

**经典稳态布居不是光化学产物分支比。** 光化学问题请使用插件 C1 加权首达概率分析。

### 第三站：平均首达时间 MFPT

选择目标态，从表格查看每个起点到目标的平均首次到达时间，单位与模型一致。示例理论上 0→1 平均为 10 steps，1→0 平均为 5 steps；估计值会有波动。

这是平均值，不是保证每条轨迹都在同一时刻到达；目前没有 MFPT 的置信区间。不要把 MFPT、lag 与慢弛豫时间混为一谈。

### 第四站：ITS 与 CK

先看中文结论：已测试 lag 上得到支持、数据不足、或假设未获支持。负向结论也会显示完整图表，便于检查问题。

- ITS 表展示各 lag 的最慢衰减时间，关注是否稳定与是否振荡。当前检查是至少三个 lag 的最慢衰减时间跨度小于 30%，属于启发式。
- CK 比较多步预测与留出的整条轨迹，展示加权 RMSE、支持行数及阈值。缺数据不算通过。
- 展开诊断查看原始检查、数据摘要与来源。导入模型时重算矩阵、布居与谱一致性；没有原始轨迹时无法重新审计保存的 ITS/CK 统计。

通过有限数据检验不能证明真实动力学一定满足马尔可夫假设。

## 4. 导入自己的模型

1. 先用 `th_msm_build` 或 `th_msm_run` 生成经典 **model.json**。
2. 点击 **导入自己的 model.json**，选择文件。
3. 检查页面显示的数据来源、单位、lag、训练及留出轨迹数。
4. 点击 **下载当前模型** 保存当前 JSON；点击 **打印 / 保存 PDF** 导出可阅读结果。

网页只读取你主动选择的文件，不扫描硬盘。当前支持 `kind: classical-msm`、schema v1、2–128 状态；模型文件上限 8 MiB。网络和热图只显示前 16 态，起点/目标选择、完整转移行、布居与 MFPT 仍覆盖所有状态。大状态数的浏览器稠密计算可能较慢。

不能直接导入原始 XTC/DCD、离散轨迹输入 JSON 或非绝热 run/C1 JSON。请先经插件建立模型；原始轨迹特征提取仍未实现。

## 5. 源码开发者启动

```bash
npm ci --ignore-scripts
npm run build
npm run web
```

终端输出 `http://127.0.0.1:随机端口/`，复制到浏览器。服务只监听本机，只提供网页，不暴露工作区文件，没有远程执行接口。Ctrl+C 停止。构建同时生成 `dist/th-msm-web.html`，可直接双击或分享这个文件。

Codex 插件包中同样附带 `web/index.html`。分享包含真实模型的导出网页时，该模型数据也在 HTML 中；公开前请确认数据适合分享。

## 6. 常见问题

**没有图？** 先点“打开两状态教学示例”，或导入模型。独立教学 HTML 默认不会自动加载模型。

**提示 INVALID_MODEL？** 文件不是当前支持的模型，或计数、矩阵、布居、谱不一致。重新建立模型，不要手改概率使其“好看”。

**CK 没通过怎么办？** 检查独立采样、特征、状态与 lag；让插件解释失败明细。不要只改阈值直到通过。

**能在网页直接建立真实模型吗？** 当前网页用于解读已有模型与交互教学。建模、环境检查和脚本导出仍由插件或 Node 工作流完成。
