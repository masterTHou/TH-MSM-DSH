# TH-MSM v1.4.0 — 从问答到建模：经典 MSM、分层教学与 TypeScript 核心

本版重新明确三个产品入口：**MSM 学习、经典 MSM 建模与结果分析、非绝热 C1/WE 研究**。面向客户与个人科研使用，优先让问答窗口里的流程容易开始、容易理解。

## 在 DSH 中直接说

- “我是新手，用两状态例子解释 MSM。”
- “我没有数据，带我跑第一个模型。”
- “数据在 data/classical.json，帮我建立 MSM。”
- “解释模型结果，并计算到状态 1 的 MFPT。”

向导每轮给 1–3 个相关问题、选项和示例回答，记住同一会话已给的信息；切换目标时清理不相关数据。数据类型可自动识别，已有模型会进入结果分析。信息齐全且已授权时不重复询问确认。

## 实际新增能力

- 基础经典 MSM：离散轨迹或预提取特征、训练集 KMeans、滞后计数、非可逆行 MLE、稳态布居、谱与衰减时间尺度、MFPT。
- 多 lag ITS 与独立留出轨迹 CK 诊断。缺数据、不连通或检验不支持时明确报告，不伪造模型适用性。
- 12 个教学主题、入门/研究生/专家层次、数值例子、小练习、误区和学习路线。
- 新增 `th_msm_guide`、`th_msm_example`、`th_msm_analyze`；建模、验证和报告工具同时支持经典 MSM 与原有非绝热工作流。
- 严格 TypeScript 用于科学契约、轨迹校验与新的 MSM/教学/决策模块，统一编译为 JS 并附 .d.ts。原有 JS 为渐进迁移，非绝热数值行为保持原先约定。
- 借鉴 Jev 的结构化决策接口：共享状态、有限选项、明确输出和不确定时补问。当前为本地规则，未接入 Jev API，规则分数不伪装成校准概率，也不控制科学跃迁或权重。
- README 重新设计，新增原创 SVG 概览、真实对话示例、可手算的两状态结果与能力范围表。

## 验证与安装

本地 Windows / Node 24：44 项测试，43 通过，1 项因符号链接权限明确跳过；类型契约检查通过。包含经典解析答案、负向 CK、训练/验证分离、会话记忆、真实 DSH 工具 schema 及原有 C1/WE 测试。

默认两状态演示估计布居约 **66.13% / 33.87%**，解析参考为 **66.67% / 33.33%**；MFPT 0→1 约 **9.82 步**，解析参考为 **10 步**。

下载 `th-msm-dsh-plugin-1.4.0.tgz` 在 DSH 安装。包内包含编译后 JS、类型声明、知识库及数值运行依赖；不要求用户安装 TypeScript、Python 或配置 Jev Key。DSH 主机仍需满足 peer dependencies。

源码体验：

```sh
npm ci --ignore-scripts
npm run demo:msm
npm test
```

## 边界

经典 dense MSM 限制 2–128 状态；ITS/CK 标记为公开阈值的有限数据诊断。π/MFPT 置信区间、XTC/DCD 直接读取、tICA/VAMP 后端、可逆 MLE/PCCA+/经典 TPT 尚未实现。非绝热 C2、外部 ES 传播、严格预算调度仍待完成。

经典 π 不替代光解首达产率。v1.3.0 的非绝热实验记录继续保留，包括“未观测到 CI-WE 效率优势”的负向结论；本版不新增加速主张。实际 DSH 桌面对话体验仍欢迎客户试用反馈。
