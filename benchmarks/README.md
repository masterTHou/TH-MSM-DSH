# v1.3.0 已执行实验

2026-10-15，在 Windows / Node 24.19.0 上执行。所有 ES 调用为零；解析模型调用单独计数。

## 目标协议 target-v2

模型：扩展非线性双 CI；FC center=(-2,-0.15)，omega_FC=0.001；dt=0.5 au；1100 步，观察窗 13.3038637962 fs。其他参数见 `target-v2.json`。冻结后使用独立种子生成 10,000 条直接参考轨迹，各方法另跑 20 个独立 runs，每 run 初始 64 个 FC 根轨迹。

参考：224/10000 = **2.24%**；95% Wilson 区间 **[1.9678%, 2.5489%]**。参考保留未吸收质量 0.4632；不将两种产物条件归一化为 100%。

| 方法 | 平均 rare 首达概率 | 独立-run bootstrap 95% | 相对方差 | RMSE 对有限参考 | 平均解析调用 |
|---|---:|---|---:|---:|---:|
| Direct | 2.1094% | [1.4844%, 2.8906%] | 0.59346 | 0.015892 | 316008.25 |
| WE | 2.5806% | [1.6724%, 3.8110%] | 0.85775 | 0.023542 | 248306.75 |
| CI-WE | 3.1787% | [2.1582%, 4.2529%] | 0.61419 | 0.026032 | 321541.75 |

与参考的均值偏差分别约 0.33、0.61、1.63 个合成标准误。三者 bootstrap 区间均覆盖参考点估计；这不能证明无偏性或底层传播器的物理正确性。

**负向结论：没有观测到效率优势。** WE 与 CI-WE 的 cost×variance 相对 Direct 分别约为 1.70 和 2.39；大于 1 表示本次诊断中更差。20 次 run 的样本方差仍有不确定性，不能视为普适性能排序。

本次参考和评估合计 66,921,015 次解析模型求值；耗时约 242.90 秒（当前机器）。该数不包含预实验/开发探针，不提供端到端开发成本加速倍数。不存在昂贵量化 ES 调用节省报告，因为分母为零。

复现：

```sh
npm run benchmark:full
```

## 保留的预实验 pilot-v1

此前以 FC center=(-2,0) 执行同规模实验，参考 373/10000=3.73%，超出预定 1%–3% 目标；普通 WE 和 CI-WE 也均未显示成本归一化方差优势。完整汇总保存在 `pilot-v1.json`，没有隐藏这个负向结果。

target-v2 只修改了 FC 参考谐振子中心，然后固定协议并使用全新的参考/评估种子。它是另一种初态分布，不能将两个协议的数据合并估计同一个分支比。初始 N=256 校准与开发探针未完整保存成本，不参与加速主张。

复现历史预实验：

```sh
node scripts/benchmark.mjs --full --profile=pilot-v1 --output=output/pilot-v1
```

## 证据与限制

JSON 汇总包含每个 run 的结果与实际成本。Release 的 `analytical-benchmark-v1.3.0.tar.gz` 附两套实验的原始事件账本、FC 初态、WE 重采样谱系、末态 checkpoints 与 C1 分析。完整连续帧默认不保存，可设置 recordFrames=true 另行运行。

这不是相同实际 ES 预算的生产性能比较；也不是精确量子动力学真值。底层 FSSH+EDC 的近似误差、时间步偏差、有限参考误差及 toy 吸收边界限制见 [SCIENCE](../docs/SCIENCE.md)。
