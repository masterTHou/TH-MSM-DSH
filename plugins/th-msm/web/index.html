01 / 状态与转移

从哪里出发，下一步去哪？

点击圆点或选择起点。箭头显示一个 lag 后的转移概率，圆点面积表示长期布居。布局仅用于阅读，不代表分子几何或能量。

02 / 转移矩阵

每一行，都是一次选择

行 = 当前状态；列 = 一个 lag 后的状态。每行概率之和为 1。点击格子阅读具体含义。

03 / 长期布居 π

长时间观察，在哪儿待得多？

布居高表示长期占比大，不能直接说明到达速度快。这里的 π 是经典模型长期布居，不能当作光化学产物分支比。

04 / 平均首达时间 MFPT

平均多久，第一次到达？

MFPT 是重复试验的平均等待时间；每次轨迹可能更快或更慢。目标态自身显示 0。尚未估计置信区间。

05 / 先验证，再解释

ITS：换个 lag，慢时间尺度还稳定吗？

不是越平越能证明模型正确。当前启发式检查比较至少三个 lag 的最慢衰减时间，跨度需小于 30%；模式可能交换。

CK：预测多步，能对上独立数据吗？

比较 Pᵏ 与留出整条轨迹的 k×lag 统计。缺少留出数据时，不能给“已验证”的结论。

展开诊断明细与数据来源
网页重算矩阵、稳态与谱的一致性；ITS/CK 沿用模型文件保存的统计，无法仅凭模型重新审计原始轨迹。通过这些有限数据检验不等于证明马尔可夫性。

支持什么？暂时不支持什么？
网页支持 TH-MSM classical-msm v1 的 2–128 状态模型。最多画 16 个状态的网络与热图，完整数值仍可从选择框和模型 JSON 读取。没有原始轨迹转换、tICA/VAMP、PCCA、可逆估计或置信区间；非绝热分析使用插件 C1 路线。
